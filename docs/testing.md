# 2.0.0 验证记录与整合包验收

## 自动检查

运行 `gradlew regressionTest`，完整构建 `gradlew build` 也会运行这些检查。

领域检查覆盖：

- 配置电路的 NBT 所有权、生成策略、网络往返；不消耗输入及独立 catalyst 槽位保留/排除。
- 处理倍率只放大消耗输入和产物，不放大电路/模具等不消耗输入。
- 概率输出出现在确定输出之前、全概率输出、空输入或空输出跳过。
- 99.99% 与 100% 的区分以及 0.01% 的显示。
- 包含大 NBT 的序列化大小和往返；恶意槽位计数在分配前拒绝。
- 搜索 AND / OR / 排除 / 前缀加引号 / 引号内竖线 / 通配符。
- GT 旧公开字段、新 record 访问器及不消耗 chance=0。
- 320×180、480×270、640×360、1920×1080 GUI 逻辑分辨率下，至少一行列表，列表不与工具栏/页脚重叠。
- 1 格、2 格、3 格宽有序配方映射到 AE2 3×3 网格。
- 手动倍率默认值、非预设值、最大值、空值、0、负数、小数、超范围和超长文本；手动倍率实际进入生成数量计算。
- 多标签归组、输入/输出侧隔离、共享勾选、无标签保留、折叠行、唯一配方生成、分组分步构建。
- 包含 NBT 的材料精确匹配、服务端预览和只读检查请求格式，以及 320×180 下 1–8 项菜单边界与命中。

这些检查不启动 Forge 游戏，不模拟 ME 网络，不代表已经验证真实 GT/JEI 组合或渲染结果。

## 手工验收清单（待整合包实测）

使用客户端及服务端同一份 `eae2-pattern-2.0.0.jar`。新协议不兼容旧客户端/服务端。推荐先在测试世界中准备一个带终端、无线接入点、空白样板和足量存储的 ME 网络。

1. **统一入口**：分别对工作台（单个工作方块）、GT 电弧炉（多列机器）、刚好排满列的类别按 U。确认入口始终位于 JEI 原生工作方块底板内，不覆盖原机器，无额外边框或背景；反复切换类别、翻页、缩放和重新打开，入口应只有一个。类别索引页和没有工作方块的类别也采用同一路径。
2. **数量与采集**：选几百/数千条配方的类别，确认进度持续更新，完成后总数合理；按取消应立即返回，不生成任何样板。采集上限 8192，不包含 JEI 隐藏配方。
3. **双侧搜索**：输入搜索 `@gtceu` 只匹配输入材料，输出搜索只匹配产物。分别检查中文、`$forge:ingots`、`#配置`、`&gtceu:`、`%`、`^red`、排除、引号和 OR。流体名称也应可搜索。
4. **概率语义**：选正常/不消耗/概率消耗输入、多个确定输出、混合概率副产物、全部概率输出的配方，逐一检查条件和详情。注意主产物为首个确定输出的显示约定。
5. **配置电路与模具**：确认配置 24 与配置 0 显示和搜索不同；默认排除不消耗材料；切到保留并设置倍率 8，电路/模具仍应为原数量。将生成样板放入机器链路，确认配方行为正确。
6. **连续列表**：滚轮上/下、拖动滚动条到首/尾、半途反向拖动，确认没有跳过或重复渲染；滚动过程中勾选保持正确。右侧详情滚动不应带动左侧。
7. **选择与过滤**：全不选 → 搜索一类材料 → 全选 → 再缩小搜索范围，生成数量应等于当前匹配且选中的有效条目。搜索切换保留选择；只看已选按钮应稳定。
8. **输出策略**：全部/仅确定/仅主产物分别生成并检查样板内容。全概率配方在后两种策略下数量为零。概率数量不按期望折算。
9. **空白样板不足**：网络少一个时客户端按钮不可用。客户端看到足够后，从另一个终端取走样板，再生成；服务端应拒绝或在并发抽走时停止，报告消耗数量真实。
10. **满盘退款**：让存储无法接收新样板；应停止，不丢空白样板。再限制网络接收空白样板，确认退到背包；背包也满时应掉落。
11. **连接检查**：有线终端、主手/副手/背包无线终端分别检查；无线无电/越界/不同维度不可生成。生成中移走终端或切换网络，应停止，已完成条目保留。
12. **编码类型**：验证 1×3、2×2、3×3、带空格形状的合成配方，以及切石、锻造、物品/流体处理配方。真实检查 AE2 是否识别并能执行生成样板。
13. **响应与清理**：多人同时生成、生成中断线/退出世界、重新进世界、JEI runtime 重载；确认不重复执行、不残留任务。卡顿比较应记录实际整合包帧时间/服务器 tick 时间，当前未提供实测内存或 TPS 基准。
14. **UI**：在 1280×720、1920×1080、超宽屏及不同 GUI 缩放下检查截字、悬浮提示、输入法、焦点、拖动和返回。小窗口截断的字段应可通过悬浮提示读取完整内容。
15. **开关与菜单**：一键切换“排除不消耗”，生成数量和内容应正确更新；条件菜单直接选择和方向键/回车选择应一致，Esc 先关闭菜单，点击菜单外收起且不误触底层列表。
16. **倍率输入**：默认 ×1，快捷选 ×8，再输入非预设值 100，确认材料和产物按 100 倍编码；不消耗电路和模具仍为原数量。清空或输入 0/65537 时按钮禁用；输入 1 恢复。默认菜单应能回到 ×1，缩放窗口保留手动值。
17. **标签分组**：切换相同产物、产物标签和输入标签，检查 `forge:plates` 与 `forge:plates/iron` 同时包含铁板配方。一个组中勾选/取消后，另一个组状态同步；多组出现不增加生成数量。无标签配方应进入“无标签”。
18. **选择范围**：折叠组不改变生成数；搜索隐藏的已选配方应计入“隐藏已选”，不发给服务器。组方框选择整组，全选/清空影响所有当前匹配结果。反选/只看已选应在更多菜单中可用。
19. **比较与 JEI 返回**：固定原配方 A 为对照，点击不同输入路线 B；宽窗口并排，窄窗口上下，两边均显示原配方完整材料。JEI 按钮打开 B 原配方，返回后工作台筛选、倍率和勾选保持，退出工作台后不应陷入 JEI/工作台循环。
20. **最终编码预览**：设置输入黑名单、容器过滤、倍率及输出策略，最终样板应与真实生成结果一致。对窄有序配方、流体 NBT、配置电路分别检查；快速切换行或策略不能显示旧请求结果，不消耗空白样板。合成替代品显示一个代表选项。
21. **图标交互**：列表按空间显示 3/2 或 2/1 个输入/输出，超出为 +N；悬浮图标有数量、概率和物品 tooltip。水、熔融金属等纹理和颜色不同。点击配置 24 的电路只匹配相同 NBT，编辑搜索框后恢复普通搜索。
22. **已有样板检查**：ME 存储放入一张与当前策略完全一致的样板，主动检查后只取消勾选该条；倍率/NBT不同不应误判。供应器里的样板不应算作 ME 存储已有。检查不扣物品，缺空白样板仍可检查，检查中断网不能应用部分结果。
23. **偏好与跳过**：退出后重开，应记住四项本地偏好；恢复默认应回到 ×1、全部输出、排除不消耗、不分组。原配方无确定输出、过滤空输入、槽位超限和服务端预览失败应能查看原因。

## 日志

客户端：`Collected ...`、`Sent ... pattern specs ... chunk(s)`。

服务端：`Generation for ... requested=... inserted=... skipped=... reason=...`。

结果包含 `COMPLETED`、`NOT_ENOUGH_BLANK_PATTERNS`、`STORAGE_FULL`、`NO_NETWORK`、`TOO_MANY_PATTERNS`、`ENCODE_FAILED`。逐条跳过原因在 debug 日志中，最多五条回传详情、最多三条显示到聊天。
