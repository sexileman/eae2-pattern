# 预览界面原型（浏览器里点）

打开 `preview-demo.html` 就能在浏览器里试**真实的交互**，不用进游戏、不用装 mod。
双击文件即可（纯静态、无外部依赖、断网可用）。

## 它和游戏里的关系

- 画布是 **480×270 逻辑像素**，等于游戏里 **GUI 缩放 4** 的观感，所以尺寸、密度、字大都是真机的样子。
- 只用了 Java 端也能画的东西：圆角矩形、1px 描边、文字、16×16 贴图缩放。**没有**模糊、阴影、渐变、圆角抗锯齿这类"网页能做、游戏里做不到"的效果，所以能一比一搬进 mod。
- 字体会有点差别：原型用 Noto Sans SC（思源黑体同设计），游戏里用 Minecraft 自带字体（装了 ModernUI 时可用它的字体管线）。

## 怎么用

上方工具条实时改样式，画布立刻变：

| 控件 | 作用 |
|---|---|
| 皮肤 | 深色磨砂 / 午夜蓝 / 石墨灰 / 玻璃分层 / 原版浅灰（AE2·JEI 同族） |
| 强调色 | 蓝 / 青 / 绿 / 紫 / 橙 |
| 密度 | 紧凑（一行 11px）/ 舒适（13px，字大一号） |
| 圆角 | 0–8 |
| 面板不透明度 | 35%–100% |
| 毛玻璃模糊 | 0–16（0 = 关掉模糊） |
| 背景 | 毛玻璃（模糊世界）/ 纯色（不模糊） |

界面本身也是能点的：

- 两个搜索框可输入，支持 `名称`、`@模组`、`$标签`、`&资源id`、`-排除`、`|` 或。
- 六个条件勾选即时过滤；「全选 / 反选 / 去重 / 只看已选」都作用于当前筛选结果。
- 点行勾选；鼠标悬停会在右侧详情里显示这条配方；翻页在列表右下角。
- 倍率 1–64 可点，生成按钮会按勾选数量显示「生成 N 条」，点了会弹结果提示条。

## 毛玻璃是怎么做出来的

原型的做法和游戏里要做的是同一件事的三步：

1. 把"背后的世界"画到一张离屏画布（原型里是程序生成的天空+方块，游戏里是主 framebuffer）；
2. 在面板的圆角区域内，用 `blur()` 把这张图模糊后贴上去（游戏里这一步是 framebuffer 拷贝 + 降采样/模糊 pass）；
3. 再叠一层半透明深色 + 1px 浅色描边 + 卡片层的半透明玻璃，文字才压在玻璃上仍然可读。

所以原型里看到的层次（世界 → 模糊 → 深色玻璃 → 卡片 → 文字）和游戏里会完全一致。

## 定稿方式

调好后点 **「导出参数」**，下方文本框会生成一段 JSON：

```json
{
  "skin": "midnight", "accent": "#4c9aff", "density": "compact",
  "radius": 5, "panelAlpha": 0.82,
  "rowH": 11, "step": 12, "icon": 10, "checkbox": 7, "font": 7, "titleH": 15,
  "grid": { "panel": {...}, "filter": {...}, "list": {...}, "detail": {...}, "action": {...} }
}
```

把这段发我（或直接说「用午夜蓝 + 青色、圆角 5、透明度 85%」），我按这组数值改 `PreviewScreen.java`，
并且会继续用 `mirror_layout.py` 从 Java 常量反渲染截图，保证**截图和 jar 是同一套数字**。

## 深链接

想直接看某个组合，可以在地址后加参数（方便对比截图）：

```
preview-demo.html?skin=midnight&acc=1&density=cozy&radius=6&alpha=88&sel=1
preview-demo.html?skin=glass&q=钢&cond=chanceOut
```

`acc` 是强调色序号（0 蓝 / 1 青 / 2 绿 / 3 紫 / 4 橙），也可以直接给 `#rrggbb`；
`q`/`qi` 预填产物/输入搜索；`cond` 预勾条件（逗号分隔）；`sel` 预选前 5 条。
