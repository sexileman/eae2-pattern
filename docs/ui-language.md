# 界面文案约定

适用于 `ui-polish-1.20.1` 分支的界面、物品提示和操作反馈。中英文同步维护。

## 术语

| 用途 | 中文 | English |
| --- | --- | --- |
| 编码动作 | 编码 | Encode |
| 主界面 | 样板编码 | Pattern encoding |
| 通配界面 | 通配样板编码 | Wildcard encoding |
| AE2 基础消耗品 | 空白样板 | Blank pattern |
| 未编码通配物品 | 空白通配样板 | Blank wildcard pattern |
| 已编码通配物品 | 通配样板 | Wildcard Pattern |
| 确定的输出 | 必定产出 | Guaranteed output |
| 配方两侧 | 输入 / 输出 | Inputs / outputs |
| 不消耗的输入 | 不消耗材料 | Reusable inputs |

样板按“张”计数，配方按“条”计数。名称或按钮使用简短动词；操作提示补充条件、目标位置或失败后的下一步。

## 搜索提示

`@` 模组，`$` 标签，`&` 物品 ID，`#` 提示文字，`%` 创造栏，`^` 颜色。标签与物品 ID 分开说明，避免误导。

动态规则使用稳定的形态、材料和 ID 条件；名称、拼音与提示文字搜索使用固定收录。模式区别放在对应说明中，按钮不重复整段帮助。

## 帮助内容

- 主字段给出结果或状态；补充说明解释必要条件和下一步。
- 保留无线终端连接条件、概率产物的不确定性、不消耗材料的预置要求和空白样板消耗规则。
- 区分动态规则的单张限制与固定收录的拆分行为。
- 手持编码需区分单张原地更新和空白堆叠成品进入背包。
- 分组可重复展示同一配方，但不重复编码；折叠不取消勾选。
- 实现细节如压缩、载荷、缓存和预编码流程放入开发或测试说明。

## 校对

保留语言键、参数数量和参数顺序。Minecraft 翻译中的字面 `%` 用 `%%`，避免被当作格式符。发布前核对中英文键集合、格式参数、特殊符号和最终 jar 中的资源。

物品提示使用“配方类型”，与处理样板一致。通配样板提示不添加空白分隔行；仅保留编码者、配方类型和匹配数量，不附加操作说明或统计时点。
