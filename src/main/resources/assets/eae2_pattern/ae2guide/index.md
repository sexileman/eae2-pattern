# EAE2 Pattern

<ItemImage id="eae2_pattern:machine_wildcard_pattern" scale="4" />

为同一类工作方块批量编码 AE2 样板，或将多条配方收录到一张绑定机器类型的通配符样板。

- [批量编码](batch-encoding.md)：从 JEI 工作方块入口筛选、预览并编码普通样板。
- [通配符样板](wildcard-patterns.md)：获取、规则配置、网络编码和供应器使用。

## English

EAE2 Pattern encodes machine recipes in batches, or collects recipes in a wildcard pattern bound to one machine type.

See [batch encoding](batch-encoding.md) and [wildcard patterns](wildcard-patterns.md). Each page includes an English summary.
